My Own DBMS - Development Progress

Project Overview

My Own DBMS is a relational database written from scratch in Go, open source and built for learning. It has no external dependencies: the lexer, parser, on-disk format, indexes, transactions and network server are all implemented in the project itself, with code small enough to read top to bottom.

What already works

  • Lexer and parser: hand-written lexer and recursive descent parser producing a typed AST, both fuzzed.
  • SQL: CREATE/DROP TABLE, INSERT, SELECT, UPDATE, DELETE, CREATE/DROP INDEX and EXPLAIN, with INT, TEXT, NOT NULL, PRIMARY KEY and UNIQUE.
  • Storage: slotted pages, a binary record format with a NULL bitmap, and stable row ids.
  • Indexes: B+tree indexes with byte-sortable keys, used to enforce keys and to speed up queries.
  • Transactions: every command is atomic, protected by a rollback journal with crash recovery.
  • Query planning: SQL three-valued logic and a rule-based planner that picks a full scan or an index range.
  • Server: a REPL and a concurrent TCP server speaking JSON lines.
